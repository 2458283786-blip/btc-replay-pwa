# K线复盘 · 趋势判断训练（PWA）

随机截取一段 K 线练习趋势判断的复盘工具，手机端「添加到主屏幕」后即可像 App 一样使用，支持离线缓存。

## 本地运行

```bash
python -m http.server 8080 --directory .
```

然后手机/电脑浏览器打开 `http://你的IP:8080`（同一局域网）即可体验。注意 Service Worker 在 `localhost` / `127.0.0.1` / `https` 下才生效。

## 部署上线（二选一）

### 方式一：Netlify（最简单，拖拽上传）

1. 打开 https://app.netlify.com/drop
2. 把 `btc-replay-pwa` 文件夹直接拖进页面
3. 完成后会得到一个 `https://xxx.netlify.app` 链接，手机浏览器打开后「添加到主屏幕」

### 方式二：GitHub Pages

1. 新建 GitHub 仓库，把 `btc-replay-pwa` 里的文件推上去
2. 仓库 Settings → Pages → 选择分支和根目录部署
3. 完成后得到 `https://用户名.github.io/仓库名/`，手机打开后「添加到主屏幕」

每次修改代码后推送即可自动更新（Service Worker 会缓存新版本，第二次打开生效）。

## 功能说明

- **随机抽取**：设置里选交易对、时间范围、起始可见 K 线数，随机截取一段
- **逐根回放**：播放 / 暂停 / 上一根 / 下一根 / 揭晓全部，速度可调
- **开仓设置**：开多 / 开空时可设止盈、止损（百分比），触发后自动平仓并记录
- **复盘报告**：揭晓后自动给出本段真实走势统计（涨跌幅、最大涨幅/回撤、平均振幅、放量位置），逐笔判定顺势/逆势与对错
- **笔记与历史**：每轮可写复盘笔记；历史记录按日期保存，可重新复盘同一段、删除、导出 CSV / JSON
- **进步统计**：累计复盘次数、总胜率、累计盈亏、每轮正确率曲线、盈亏曲线
- **画线**：趋势线 / 水平线 / 斐波那契回撤
- **横屏与缩放**：支持手机横屏看盘（横屏自动隐藏成交量、压缩按钮区给图表让空间）；页面级缩放已锁定，只有图表区域支持捏合缩放
- **数据源**：
  - `Binance 实时行情`：真实数据，需要网络能访问 Binance（部分地区受限会失败）
  - `内置模拟行情`：离线可用，数据由本地算法生成，练习功能完全不受影响
- **离线**：首次加载后，页面与应用脚本会被 Service Worker 缓存，断网也能打开；拉取过的 K 线数据缓存在 IndexedDB

## 数据说明

- 所有复盘记录保存在浏览器 `localStorage`，仅存本机，请定期用「导出 JSON」备份
- K 线缓存保存在 IndexedDB，数据量较大时可删除站点数据释放空间
